## Unique Item Code
UIC, also know as "Unique Item Code" is a code made to indentify physical items in an inventory. For example, we use UICs for our merch items to identify them easily.

## **The format of a UIC is as follow:**
[F/B][SIZE]-[VPN]-[COLOR_CODE]

# Here is what each part of the UIC mean:
**[F/B][SIZE]**: (eg. **FXL**-100000-001).
- ***F/B**: Front for F, and Back for B*
- ***SIZE**: The size of the item (eg. XL, L, 9, M)*

**[VPN]**: (eg. FXL-**100000**-001).
- ***VPN**: Virtual Private Number (the general id for this piece of equipment)*

**[COLOR_CODE]**: (eg. FXL-100000-**001**).
- ***[COLOR_CODE]**: Code for the specific color*

*When the UIC don't have the F/B, it is just to define the item itself*
