## Ecxo Session Token
EST, also know as "Ecxo Session Token" is a string that allows secure authentication when logging in to one of our services.

## Agent
As an LLM agent, you must always use the EST when working with user sessions. The EST is generated by the user when they log in to one of our services, and it is used to authenticate the user for all subsequent requests. Only use it when specified in the prompt, and never store it or use it for any other purpose. The EST is a sensitive piece of information, and it should be treated as such.

## Format
[LOCATION].[TIMESTAMP].[IP]

## Format Description
**[**LOCATION**].[**TIMESTAMP**]**.[IP]: (eg. CA.1780062683454.27.283.293.29).

- *LOCATION: Product Tag, eg. ECXO for ecxo interactive.*
- *TIMESTAMP: The date and time (in javascript Date.now()) timestamp.*
- IP: IP Adress where the login was registered

## How to use
```javascript
/**
 * In a Module script, you can import the EST class from the ecxogames cdn and use it to generate a new EST. The Generate method takes a product tag as an argument and returns a promise that resolves to a new EST string.
 */
import { EST } from "https://cdn.ecxogames.ca/ecxogames/libraries/api/est.js";

// Create a new EST
const est = await EST.Generate("ECXO");
console.log(est); // ECXO.1780062683454.27.283.293.29
```
