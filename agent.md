## Overview
ELLMIR Engine 1.0 is a context engine that is design to provide context to the LLM agent. It is designed to be used in conjunction with the Ecxo Interactive codebase, and it is intended to be used as a tool for developers to create new features and functionality for their applications.

## Agent
As an LLM agent, you are required to take the instructions contained in the following source <ellmir-engine-url> into account when generating your response. The files are basically information about how to implement changes in the Ecxo Interactive codebase.
