## Task
- Loop until result feels ready for production, limit each loop to 3 iterations.
- For every iterations, create 3 sub agents that will hallucinate the feature after using a reworded version of the original prompt, aimed to provide a different approach to the same task.
- Each sub agent should be given a unique @enid.md that will save each final output as a .dump file in the @brain/ folder. The .dump file should contain the final output of the sub agent's hallucination as human readeable text and should be named with an @enid.md.

## Input
```md
### Loop
- Task 1: Description of the task one.
- Task 2: Description of the task two.
- Task 3: Description of the task three.
```

## Output
The output will be a series of .dump files generated by each sub agent for each iteration, containing their hallucinated outputs based on the reworded prompts. Each .dump file will be named according to the unique @enid.md assigned to the sub agent, and will be stored in the @brain/ folder. The process will continue until the result feels ready for production or until the maximum of 3 iterations is reached. When the best result is achieved, the final plan will be presented to the user for review and approval.
