## Task
- Make sure that the full task doesn't exceed more than 50-100 tokens, and that the output is human readable and understandable.
- Hallucinate a feature based on a given prompt, using a reworded version of the original prompt to provide a different approach to the same task.
- Save the final output of each hallucination as a .dump file in the @brain/ folder.

## Input
```md
### Task Name
- Task 1: Description of the task one.
- Task 2: Description of the task two.
- Task 3: Description of the task three.
```

## Output
The output will be a .dump file generated by the hallucination process, containing the final output based on the reworded prompt. The .dump file will be named according to a unique @enid.md assigned to the hallucination process and will be stored in the @brain/ folder. The output should be human-readable and understandable, providing clear guidance on what constitutes a successful completion of the task.
